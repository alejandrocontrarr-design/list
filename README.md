✅ Funcionalidades para el Usuario
➕ Agregar Nuevas Tareas

El usuario puede escribir una tarea en un campo de texto.

Al presionar el botón "Agregar", la tarea se añade a una lista.

La tarea se muestra automáticamente en pantalla.

El campo de texto se limpia después de agregar la tarea.

✔️ Marcar Tareas como Completadas

Cada tarea tiene un checkbox o botón para marcarla como completada.

Al marcarla, cambia visualmente (por ejemplo, se tacha o cambia de color).

El estado se guarda automáticamente en localStorage.

Si se recarga la página, la tarea permanece marcada.

🗑️ Eliminar Tareas

Cada tarea tiene un botón para eliminarla.

Al hacer clic, se borra del array de tareas y del DOM.

localStorage se actualiza inmediatamente.

La tarea desaparece de forma permanente.

💾 Persistencia con localStorage

Las tareas se guardan automáticamente en localStorage.

Al recargar o cerrar el navegador, se recuperan las tareas.

La lista se renderiza automáticamente con los datos almacenados.

🧑‍💻 Buenas Prácticas del Desarrollador

La lógica está separada en funciones reutilizables.

Se utilizan nombres de variables y funciones descriptivos.

El código incluye comentarios útiles sin ser excesivos.

El archivo JS es modular, legible y fácil de mantener.

📦 Tecnologías Usadas

HTML

CSS

JavaScript (Vanilla)

Web Storage API (localStorage)

🏁 Cómo Usar

Escribe una tarea en el input.

Presiona el botón "Agregar".

Marca como completada cuando la termines.

Elimina tareas que ya no necesites.

Tus tareas se guardarán automáticamente.
